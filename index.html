Three internal tools I designed and built as an intern on a Skills Strategy team.

Two are strategy websites that name the five capabilities each function is investing in for the next 2 to 3 years and the signature skills that define them. The third is a gap analysis tool that pulls those signature skills, matches them against ~10,700 people across 43 roles, and returns a ranked list of where the biggest gaps sit on the biggest audience.

Each site was designed for a real leadership stakeholder. Each one was shipped. All three run as static HTML, CSS, and JavaScript with no framework.

Built by Celine Darvas · Aug 2026 · Portfolio version of production work.

01 · Strategy site

Customer Success Strategic Capabilities

Names the 5 capabilities the function is investing in, the 6 signature skills that define each one, and the sub-orgs, role families, and demand data behind every pick. Built as a stakeholder-facing reference site for leaders to point at when they need to explain the strategy in one link.

03 · Data tool

Capability Readiness Tool

The tool that ties the other two sites together. Pulls the 30 signature skills from both strategy sites, matches them against ~10,700 people across 43 roles, and returns a ranked list of which capabilities have the biggest gap on the biggest audience in your current filter. Includes a chat interface that answers structured questions about the same data (12 answer templates, deterministic renders, no hallucinated numbers).
